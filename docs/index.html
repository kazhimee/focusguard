Linux only

FocusGuard

Locks social media, Threads, games, and AI. Music and coding forums stay allowed.

WARNING Once started, it cannot be stopped
Open on GitHub Install

Blocked

Instagram, X, TikTok, Threads, Discord, YouTube, Steam, Heroic, Cursor, and AI sites.

Allowed

Spotify, Apple Music, w3schools, Coddy, Duolingo, GitHub, Stack Overflow.

Lock

systemd + hosts + process/window guard. No stop until the timer ends.

Install

git clone https://github.com/kazhimee/focusguard.git
cd focusguard
sudo ./install/install.sh
focusguard gui
